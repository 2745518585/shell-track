# 当前进度与后续方向

初版已具备实际 shell 执行、CLI 终端代理、本地 API、持久化与 WinUI 3 查看器。此文记录已实现范围与尚待验收的部分，功能细节以 [README](../README.md) 和 [API](protocol.md) 为准。

## 初版已完成

| 范围 | 当前结果 |
|---|---|
| ConPTY | 支持 cmd / PowerShell 单次命令与交互输入，处理尺寸、退出码与所属进程资源 |
| 后台 | 每数据目录单实例、自动启动、16 任务并发限制、进程树终止 |
| 存储 | JSON 元数据、原始输出文件、尺寸 JSONL、7 天保留、单任务与总配额、恢复为 Interrupted |
| API / CLI | 认证、分页、创建幂等、查询、跟随、停止、删除、导出、状态事件与终端专用连接 |
| 桌面 | 原生任务卡片、最新输出预览、带逻辑行号的只读日志、换行、悬停与选中、可收起详情、管理操作、托盘 |
| DPI | PerMonitorV2，150% 下整体字体清晰度由用户确认恢复 |
| 通知设置 | 结束/多个输出正则的 OR 条件、运行中编辑、首次触发去重、匹配摘要与发送诊断 |
| 工程 | 原创多尺寸图标、构建与发布脚本、许可证收集、Windows CI 和真实进程集成检查 |
| 安装 | 自包含 EXE/MSIX、签名与公开证书、用户 PATH/执行别名、保留数据的卸载与安装验证 |
| 发布 | 版本标签触发 GitHub Release、签名 ZIP/EXE/MSIX、SHA-256 与构建来源证明、Environment 配置指南 |

## 仍需完成实际验收

2026-10-03 排查完成通知，确认调用方继承的 MSIX 注册表虚拟化造成桌面无法读取通知激活器。程序补充桌面代理启动、实际数据路径解析、快捷方式身份和前台权限处理。全部旧版查看器退出后，新版通知显示、点击定位、托盘和前台窗口由用户确认正常。EXE/MSIX 安装场景与其他机器仍需验收，不能把提交结果视作显示成功。证据与复测步骤见 [通知说明](notifications.md)。

交互测试已覆盖 API 输入和真实 shell，但 Tab、方向键、中文输入法、粘贴、Ctrl+C 与各终端宿主的控制台恢复仍应在用户桌面持续验收。测试不能替代完整终端体验验证。

窗口目前是纯文本日志视图，常见回车覆盖可读，全屏程序和复杂光标移动不能完整重现。不同 DPI 显示器间拖动、100% / 125% / 150% / 200% 缩放、窄窗口和高输出量的滚动体验应继续人工验证。

磁盘写入失败会标记记录不完整并继续排空，但真实磁盘耗尽、突然断电和文件损坏恢复还需要更完整的故障注入与诊断。当前存储没有数据库事务。

## 下一阶段

1. 继续完成 EXE/MSIX 安装场景及其他机器的 Windows 通知验收。
2. 完善日志搜索、行定位、输出缺口标记、筛选与保存界面偏好，测试大量历史任务的响应与资源占用。
3. 设计交互 CLI 的重新接管输入与显式 detach 操作，保证唯一输入所有者的语义。
4. 完善后台日志、连接恢复诊断与存储故障注入。需要事务和索引时再考虑 SQLite。
5. 完善正式可信签名、自动更新、通知注册清理和升级中运行任务的处理；继续验证不同机器上的安装兼容性。

## 独立设计的扩展

交互式 shell 内逐命令追踪需要 shell 集成；完整终端回放需要终端模拟器与屏幕检查点。自动化 SDK 稳定性、持久化事件订阅与远程访问也需要独立设计。目前不承诺这些能力。
